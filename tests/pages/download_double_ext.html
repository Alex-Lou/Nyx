Double extension

Clique sur le lien : Nyx doit afficher AskDanger (rouge), pas auto-download.

Télécharger invoice.pdf.exe

Attendu :

  • Le nom invoice.pdf.exe est passé au download_policy::analyze.
  • detect_double_extension détecte (pdf hidden, exe real).
  • Verdict::AskDanger → dialog confirmation avec bouton rouge.
  • Annuler → temp file supprimé immédiatement.
  • Confirmer → fichier déplacé vers ~/Downloads/ avec sidecar .nyxmeta.

Note : la data: URL ne contient que PK\x03\x04 (signature ZIP) pour simuler un payload binaire ; le sniff post-flight détectera "Zip" qui ne matche pas exe → renforce le verdict.
