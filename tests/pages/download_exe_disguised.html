Exécutable direct

Lien direct vers un payload .exe avec MIME exécutable. Cas nominal : doit déclencher AskDanger.

Télécharger setup.exe

Attendu :

  • Pre-flight : Kind::Executable + Verdict AskDanger.
  • Dialog confirmation avec bouton « Conserver » en classe destructive-action (rouge).
  • Annuler → temp file purgé immédiatement.
  • Confirmer → déplacé vers ~/Downloads/setup.exe + sidecar setup.exe.nyxmeta avec sha256/verdict/reasons.
  • Pas d'auto-open. Pas de chmod +x.
