Gérer Nyx au quotidien

Les commandes utiles, dans l'ordre où tu en as besoin. À taper dans Git Bash ou un terminal WSL, depuis le dossier du projet.

Installer Mettre à jour Compiler et lancer Vérifier Enregistrer ses modifs Branches Entretien Dépannage Où sont les données

Installer une seule fois

Les bibliothèques système dont Nyx a besoin (Ubuntu / WSL), puis la récupération du projet.

$ sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libsqlcipher-dev pkg-config
$ git clone https://github.com/Alex-Lou/Nyx.git
$ cd Nyx
$ git switch develop

Mettre à jour avant chaque séance

Récupère les derniers changements de develop.

$ git switch develop
$ git pull origin develop
$ git log --oneline -5   # les 5 derniers commits

Tu avais des modifs en cours

$ git stash               # met tes modifs de côté
$ git pull origin develop
$ git stash pop           # les remet

Repartir d'une copie propre

$ git fetch origin
$ git reset --hard origin/develop

Attention : reset --hard efface définitivement tes modifs locales non commitées.

Compiler et lancer

$ cargo run --bin nyx                   # compile si besoin puis lance
$ cargo run --release --bin nyx         # version optimisée, plus fluide
$ cargo build --workspace               # compile seulement

Au premier lancement, Nyx demande de créer la phrase secrète du coffre (mots de passe). Retiens-la : elle ne peut pas être récupérée.

Vérifier avant de pousser

$ cargo test --workspace                # tous les tests
$ cargo clippy --workspace --all-targets # doit afficher 0 warning
$ cargo fmt --all                       # remet le code en forme

Tester une seule partie

$ cargo test -p nyx-core                # logique pure (URL, sécurité, réglages)
$ cargo test -p vault                   # coffre chiffré
$ cargo test -p nyx                     # navigateur (GTK)
$ cargo test -p nyx-core url            # seulement les tests dont le nom contient "url"

Enregistrer ses modifs

$ git status                            # ce qui a changé
$ git diff                              # le détail
$ git add -A
$ git commit -m "fix(ui): description courte"
$ git push origin develop

Préfixes de message utilisés dans le projet : feat nouveauté, fix correction, perf performance, refactor réorganisation, docs, chore.

Annuler

$ git restore chemin/du/fichier.rs      # annule les modifs d'un fichier
$ git reset --soft HEAD~1               # défait le dernier commit, garde les modifs

Travailler sur une branche optionnel

Pour essayer une idée sans toucher à develop.

$ git switch -c feat/mon-idee            # crée la branche depuis develop
$ git push -u origin feat/mon-idee
$ git switch develop
$ git merge feat/mon-idee               # rapatrie l'idée dans develop
$ git branch -d feat/mon-idee            # supprime la branche locale

Entretien

Mettre à jour les listes anti-pub

$ bash scripts/update-filterlists.sh
$ rm -rf ~/.cache/nyx/filters
$ cargo build --workspace

Libérer de la place

$ cargo clean                           # supprime target/ (plusieurs Go)

Mettre Rust à jour

$ rustup update

Dépannage

SymptômeSolution
Un changement n'apparaît pasRelance cargo run --bin nyx. cargo clippy seul ne recompile pas le binaire.
package `browser` not foundLe paquet s'appelle nyx : -p nyx ou --workspace.
webkit2gtk-4.1 not foundInstalle les bibliothèques de la section Installer.
Fenêtre vide sous WSLVérifie que WSLg marche : echo $DISPLAY doit afficher une valeur.
Push refuségit pull origin develop, règle les conflits, puis repousse.
Pubs non bloquées après MAJrm -rf ~/.cache/nyx/filters puis relance.
